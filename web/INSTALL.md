# 설치와 관리 안내

할 일 보드 웹 앱을 iPad Air 2에 설치하고 관리하는 방법입니다.

주소는 https://seujung.github.io/kid-board/ 입니다.

## 처음 설치

1. Safari로 위 주소를 열고 공유 버튼을 누른 뒤 "홈 화면에 추가"를 누르십시오.
2. 설정 > 디스플레이 및 밝기 > 자동 잠금을 "안 함"으로 정하십시오. 웹 앱은 화면이 꺼지는 것을 직접 막지 못합니다.
3. 설정 > 손쉬운 사용 > 사용법 유도 접근을 켜십시오. 홈 화면의 앱을 연 상태에서 사용법 유도 접근을 시작하십시오.
4. 설정 > 일반 > 키보드에서 한국어 키보드를 추가하고 "받아쓰기 활성화"를 켜십시오. 키보드의 마이크 버튼으로 할 일 제목을 말로 입력할 수 있습니다.
5. 설정 > Apple 계정 > iCloud에서 iCloud Drive를 켜십시오. 파일 앱의 iCloud Drive에 `할 일 보드 백업` 폴더를 만드십시오.
6. 설정 > Safari에서 "방문 기록 및 웹사이트 데이터 지우기"를 누르지 마십시오. 이 버튼을 누르면 보드의 데이터가 사라질 수 있습니다. 홈 화면 앱의 데이터도 지워지는지는 아래 "iPad 점검 목록"의 6번으로 확인하십시오. 백업 방법은 아래에 있습니다.

보드 오른쪽 위의 설정 아이콘을 3초 동안 누르면 부모 모드가 열립니다. 처음 열면 PIN을 정합니다. 이어서 8자리 복구 코드가 한 번만 나옵니다. 종이에 적어 두고 "적어 두었어요"를 누르십시오.

## 백업

백업은 PIN과 복구 코드를 담지 않습니다.

1. 홈 버튼을 세 번 눌러 사용법 유도 접근을 잠시 끄십시오. 켜 둔 채로는 공유 화면과 파일 선택이 막힐 수 있습니다.
2. 부모 모드 > 백업 > "백업 파일 저장"을 누르십시오.
3. 공유 화면에서 "파일에 저장"을 고르십시오.
4. iCloud Drive > `할 일 보드 백업` 폴더를 고르고 저장하십시오.
5. 사용법 유도 접근을 다시 켜십시오.

마지막 백업 후 7일이 지나면 부모 모드 첫 화면에 "백업한 지 N일 지났어요"가 나옵니다.

## 복원

1. 홈 버튼을 세 번 눌러 사용법 유도 접근을 잠시 끄십시오.
2. 부모 모드 > 백업 > "백업에서 복원"을 누르십시오.
3. iCloud Drive > `할 일 보드 백업` 폴더에서 백업 파일을 고르십시오.
4. "지금 데이터를 백업 내용으로 바꿀까요?"에서 "바꾸기"를 누르십시오.
5. 사용법 유도 접근을 다시 켜십시오.

복원해도 지금 기기의 PIN과 복구 코드는 그대로입니다. 백업에는 PIN과 복구 코드가 없기 때문입니다.

## PIN과 복구 코드

복구 코드는 PIN을 처음 정할 때 한 번만 나옵니다. 부모 모드의 "복구 코드 새로 만들기"를 누르면 새 코드가 나오고 이전 코드는 쓸 수 없게 됩니다.

PIN을 잊었으면 PIN 입력 화면에서 "PIN을 잊었어요"를 누르십시오. 그다음 복구 코드를 입력하십시오. 5회 연속 틀리면 1분 동안 입력이 막힙니다.

둘 다 잊었으면 앱 안에서는 복구할 수 없습니다. 다음 순서로 웹사이트 데이터를 지우고 백업에서 복원하십시오.

1. 홈 화면의 앱을 완전히 닫으십시오.
2. 설정 > Safari > 고급 > 웹사이트 데이터를 여십시오.
3. `seujung.github.io`를 찾아 지우십시오.
4. 홈 화면의 앱을 다시 여십시오. 처음 설치한 상태로 시작합니다.
5. 새 PIN을 정하고 새 복구 코드를 적어 두십시오.
6. 위의 "복원" 절차로 백업 파일을 불러오십시오.

홈 화면 앱은 Safari와 따로 데이터를 저장하므로 2~3번으로 지워지지 않을 수 있습니다. 4번에서 PIN 입력 화면이 그대로 나오면 다음 순서로 하십시오.

1. 홈 화면의 보드 아이콘을 길게 누르고 "북마크 삭제"를 누르십시오. 아이콘을 지우면 그 홈 화면 앱의 데이터도 지워집니다.
2. Safari로 https://seujung.github.io/kid-board/ 를 열고 "홈 화면에 추가"로 다시 추가하십시오.
3. 위의 5~6번을 하십시오. 그다음 사용법 유도 접근을 다시 켜십시오.

두 방법 중 이 iPad에서 어느 방법이 되는지는 "iPad 점검 목록"의 5번으로 미리 확인하십시오.

백업 파일이 없으면 이전 데이터는 되살릴 수 없습니다.

## 데이터 복구

이 절차는 보드에 "데이터를 열 수 없어요"가 나올 때만 따르십시오. 이 화면은 저장된 데이터가 손상되었거나 더 새로운 버전의 데이터라는 뜻입니다.

1. 백업 파일이 있으면 "PIN과 복구 코드" 절의 1~4번을 따라 `seujung.github.io` 데이터를 지우십시오. 데이터가 지워지지 않으면 같은 절의 홈 화면 아이콘 방법을 쓰십시오.
2. 앱을 다시 열고 위의 "복원" 절차로 백업 파일을 불러오십시오.

백업 파일이 없으면 앱 안에서는 데이터를 되살릴 수 없습니다.

## "데이터를 불러오지 못했어요"가 나올 때

이 화면은 iPad가 저장 공간을 잠시 열지 못했다는 뜻입니다. 데이터는 그대로 남아 있습니다. 웹사이트 데이터를 지우지 마십시오. 지우면 마지막 백업 뒤의 데이터가 모두 사라집니다.

1. "다시 시도"를 누르십시오.
2. 같은 화면이 다시 나오면 앱을 완전히 닫았다가 다시 여십시오. 앱 전환 화면을 열고 앱을 위로 밀어 올리면 닫힙니다.
3. 그래도 나오면 iPad를 다시 시동하십시오. 그다음 앱을 여십시오.

## 새 버전

새 버전이 배포되어도 자녀가 쓰는 중에는 화면이 바뀌지 않습니다. 새 버전은 다음 중 한 경우에 적용됩니다.

- 밤 10시부터 아침 6시 사이에 5분 동안 아무것도 누르지 않았을 때
- 부모 모드 첫 화면에서 "새 버전 적용"을 눌렀을 때
- 앱을 닫았다가 다시 열었을 때

새 버전 때문에 앱이 동작하지 않으면 앱을 완전히 닫으십시오. 앱 전환 화면을 열고 앱을 위로 밀어 올리면 닫힙니다. 수정된 버전이 배포된 뒤에 다시 여십시오.

## 야간 모드

밤 10시부터 아침 6시까지 보드를 검은 막으로 덮고 시계만 어둡게 보여 줍니다. 웹 앱은 화면 밝기를 바꿀 수 없으므로 백라이트는 켜진 채로 남습니다. 화면을 누르면 30초 동안 보드가 보입니다. 부모 모드가 열려 있는 동안에는 어둡게 하지 않습니다.

밝기를 낮추려면 설정에서 직접 낮추십시오.

## iPad 점검 목록

설치한 뒤와 새 버전을 배포한 뒤에 iPad Air 2에서 다음을 확인하십시오. 5번과 6번은 데이터를 지우므로 백업 파일을 저장한 뒤에 하십시오.

1. 홈 화면의 앱이 전체 화면으로 열립니다.
2. 가로 1024×768 화면에서 잘리거나 겹치는 곳이 없습니다. 상태 표시줄이 설정 아이콘과 부모 모드 위쪽을 가리는지도 보십시오.
3. 앱을 완전히 닫았다가 다시 열어도 데이터가 남아 있습니다.
4. 받아쓰기로 할 일 제목을 입력할 수 있습니다.
5. 데이터 지우기: 설정 > Safari > 고급 > 웹사이트 데이터에서 `seujung.github.io`를 지우십시오. 그다음 앱을 다시 열고 보드가 처음 설치한 상태로 시작하는지 확인하십시오. 처음 상태가 되지 않으면 홈 화면 아이콘을 지우십시오. 그다음 아이콘을 다시 추가하고 처음 상태가 되는지 확인하십시오. 어느 방법이 되는지 이 안내에 적어 두십시오. 확인한 뒤에 백업에서 복원하십시오.
6. 설정 > Safari > "방문 기록 및 웹사이트 데이터 지우기"를 누르십시오. 그다음 홈 화면 앱의 데이터가 남아 있는지 확인하십시오. 데이터가 지워졌으면 백업에서 복원하십시오.
7. Wi-Fi를 끄고 앱을 다시 열어도 보드가 동작합니다.
8. 1초 시계가 밀리지 않습니다.
9. 백업 파일 저장과 복원이 됩니다. 공유 화면이 열리는지, 파일 선택 화면이 "백업에서 복원" 버튼 근처에 바르게 열리는지 보십시오.
10. 백업 파일을 고르는 화면을 2분 넘게 열어 두어도 부모 모드가 닫히지 않습니다. 파일 선택을 취소한 뒤에는 2분 뒤에 부모 모드가 닫힙니다.
