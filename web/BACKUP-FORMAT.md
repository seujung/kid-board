# 백업 파일 형식

이 문서는 웹 앱의 백업 파일 형식을 설명합니다. 이 형식은 웹 앱 전용입니다. 네이티브 앱은 이 파일을 읽지 않습니다.

## 파일

- 파일 이름은 `kid-board-backup-YYYYMMDD.json`입니다. 날짜는 백업한 날의 iPad 현지 날짜입니다.
- 내용은 UTF-8 JSON 객체 하나입니다.
- PIN 해시, PIN salt, 복구 코드 해시, 복구 코드 salt, 잠금 상태는 넣지 않습니다.

## 최상위 필드

| 필드 | 형식 | 설명 |
| --- | --- | --- |
| `schemaVersion` | 숫자 | 문서 형식 버전입니다. 현재 값은 `1`입니다. |
| `data` | 객체 | 자녀, 할 일, 일정, 시각, 완료 기록입니다. |
| `settings` | 객체 | 날씨 지역, 시드 기록, 마지막 백업 시각, 화면 끄기 시간, 완료 소리입니다. |
| `weather` | 객체 또는 `null` | 마지막으로 받은 날씨입니다. 캐시이므로 형식이 틀리면 버립니다. |

## `schemaVersion`

| 값 | 앱의 처리 |
| --- | --- |
| `1` | 읽습니다. 빠진 선택 필드는 기본값으로 채웁니다. 모르는 필드는 버립니다. |
| `1`보다 큼 | 더 새로운 앱이 만든 파일입니다. 읽지 않고 "백업 파일을 읽을 수 없어요"를 표시합니다. |
| 그 밖의 값, 필드 없음 | 손상된 파일로 봅니다. 읽지 않고 "백업 파일을 읽을 수 없어요"를 표시합니다. |

형식을 바꾸면 `schemaVersion`을 올립니다. 그리고 `web/src/store/schema.ts`의 `migrate`에 이전 버전을 올리는 단계를 더합니다.

## 공통 값 형식

| 이름 | 형식 | 예 |
| --- | --- | --- |
| 날짜 | `{ "year": 숫자, "month": 1~12, "day": 1~31 }` | `{ "year": 2026, "month": 11, "day": 19 }` |
| 시각 | `{ "hour": 0~23, "minute": 0~59 }` | `{ "hour": 8, "minute": 20 }` |
| 요일 | 1~7 숫자 | 1은 월요일, 7은 일요일입니다. |
| 시간대 | `"morning"` 또는 `"evening"` | 아침 또는 저녁입니다. |
| 시점 | 숫자 | 1970-01-01 UTC부터 지난 밀리초입니다. |

날짜는 시간대와 관계없이 숫자 그대로 저장합니다.

## `data`

`data`에는 아래 배열 다섯 개가 모두 있어야 합니다. 비어 있어도 됩니다.

### `data.children` 자녀

| 필드 | 형식 | 설명 |
| --- | --- | --- |
| `id` | 문자열 | 자녀 ID입니다. |
| `name` | 문자열 | 이름입니다. |
| `avatar` | 문자열 | 아바타 이모지입니다. |
| `themeColor` | 문자열 | 테마 색 이름입니다. |
| `order` | 숫자 | 보드에 놓이는 순서입니다. 작은 값이 먼저 옵니다. |

### `data.tasks` 할 일

| 필드 | 형식 | 설명 |
| --- | --- | --- |
| `id` | 문자열 | 할 일 ID입니다. |
| `childID` | 문자열 | 자녀 ID입니다. |
| `title` | 문자열 | 할 일 이름입니다. |
| `icon` | 문자열 | 아이콘 이모지입니다. |
| `order` | 숫자 | 같은 시간대 안의 순서입니다. |
| `createdAt` | 시점 | 만든 시점입니다. 없으면 `0`으로 읽습니다. |
| `archivedOn` | 날짜 또는 `null` | 보관한 날입니다. 이날부터 보드에 보이지 않습니다. |

### `data.schedules` 일정

| 필드 | 형식 | 설명 |
| --- | --- | --- |
| `id` | 문자열 | 일정 ID입니다. |
| `taskID` | 문자열 | 할 일 ID입니다. |
| `slot` | 시간대 | 할 일이 보이는 시간대입니다. |
| `weekdays` | 요일 배열 | 할 일이 보이는 요일입니다. |
| `startOn` | 날짜 | 일정이 시작하는 날입니다. |
| `endOn` | 날짜 또는 `null` | 일정이 끝나는 날입니다. `null`이면 끝나지 않습니다. |

일정을 바꾸면 앱이 이전 일정을 어제로 끝내고 오늘부터 새 일정을 만듭니다. 그래서 할 일 하나에 일정이 여러 개 있을 수 있습니다.

### `data.times` 요일별 시각

| 필드 | 형식 | 설명 |
| --- | --- | --- |
| `childID` | 문자열 | 자녀 ID입니다. |
| `weekday` | 요일 | 요일입니다. |
| `schoolTime` | 시각 또는 `null` | 등교 시각입니다. `null`이면 등교하지 않는 날입니다. |
| `bedTime` | 시각 | 취침 시각입니다. |

### `data.completions` 완료 기록

| 필드 | 형식 | 설명 |
| --- | --- | --- |
| `childID` | 문자열 | 자녀 ID입니다. |
| `taskID` | 문자열 | 할 일 ID입니다. |
| `day` | 날짜 | 완료한 날입니다. |
| `completedAt` | 시점 | 완료를 누른 시점입니다. |

## `settings`

| 필드 | 형식 | 설명 |
| --- | --- | --- |
| `location` | 객체 또는 `null` | 날씨 지역입니다. 형식은 아래 표와 같습니다. |
| `didSeed` | 참/거짓 | 예시 데이터를 넣은 적이 있는지 기록합니다. 없으면 거짓으로 읽습니다. |
| `lastBackupAt` | 시점 또는 `null` | 마지막으로 백업한 시점입니다. |
| `dimPeriods` | 배열 | 화면 끄기 시간입니다. 형식은 아래 표와 같습니다. 없으면 기본값(매일 22:00~06:00 한 구간)으로 읽습니다. 빈 배열이면 화면을 끄지 않습니다. |
| `sound` | 객체 | 완료 소리 설정입니다. 형식은 아래 표와 같습니다. 없거나 형식이 틀리면 기본값(`{ "enabled": true, "volume": "medium" }`)으로 읽습니다. |

### `settings.location`

| 필드 | 형식 | 설명 |
| --- | --- | --- |
| `name` | 문자열 | 지역 이름입니다. |
| `admin1` | 문자열 또는 `null` | 시·도 이름입니다. |
| `latitude` | 숫자 | 위도입니다. |
| `longitude` | 숫자 | 경도입니다. |

### `settings.dimPeriods[]`

| 필드 | 형식 | 설명 |
| --- | --- | --- |
| `id` | 문자열 | 구간 ID입니다. |
| `start` | 시각 | 시작 시각입니다. 이 분부터 화면을 끕니다. |
| `end` | 시각 | 끝 시각입니다. 이 분부터 화면을 켭니다. `start`보다 이르거나 같으면 다음 날의 시각입니다. 같으면 24시간입니다. |
| `weekdays` | 요일 배열 | 구간이 시작하는 요일입니다. 월요일 22:00~06:00은 화요일 06:00에 끝납니다. |

`dimPeriods`는 `schemaVersion` 1에 더한 선택 필드입니다. 이 필드가 없는 이전 파일도 그대로 읽으므로 `schemaVersion`을 올리지 않았습니다.

### `settings.sound`

| 필드 | 형식 | 설명 |
| --- | --- | --- |
| `enabled` | 참/거짓 | 할 일을 끝낼 때 소리를 내는지입니다. |
| `volume` | `"low"`, `"medium"`, `"high"` | 소리 크기입니다. 부모 모드의 "작게", "보통", "크게"입니다. |

`sound`도 `schemaVersion` 1에 더한 선택 필드입니다. 이 필드가 없는 이전 파일도 그대로 읽으므로 `schemaVersion`을 올리지 않았습니다. 두 필드 중 하나라도 형식이 틀리면 `sound` 전체를 기본값으로 읽습니다. 이때 파일을 손상된 파일로 보지 않습니다.

## `weather`

| 필드 | 형식 | 설명 |
| --- | --- | --- |
| `temperature` | 숫자 | 현재 기온(°C)입니다. |
| `weatherCode` | 숫자 | Open-Meteo 날씨 코드입니다. |
| `high` | 숫자 | 오늘 최고 기온(°C)입니다. |
| `low` | 숫자 | 오늘 최저 기온(°C)입니다. |
| `precipitationProbability` | 숫자 | 오늘 최대 강수 확률(%)입니다. |
| `fetchedAt` | 시점 | 날씨를 받은 시점입니다. |

## 복원할 때

- 앱은 `data`, `settings.location`, `settings.dimPeriods`, `settings.sound`, `weather`를 백업 내용으로 바꿉니다. `dimPeriods`나 `sound`가 없는 파일이면 그 값을 기본값으로 바꿉니다.
- 앱은 `didSeed`를 참으로 기록합니다. 복원한 뒤에는 예시 데이터를 넣지 않습니다.
- 지금 기기의 PIN, 복구 코드, 잠금 상태, 마지막 백업 시각은 그대로 둡니다.
- 파일을 읽을 수 없으면 아무것도 바꾸지 않습니다.
