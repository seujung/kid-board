# 자녀용 할 일 보드 iPad 앱 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 자녀 2명의 할 일 보드를 한 화면에 표시하는 iPad 앱을 만듭니다. 무료 계정 서명을 자동 갱신하는 Mac mini 재설치 스크립트도 만듭니다.

**Architecture:** 화면과 무관한 로직(일정 계산, 표시 규칙, 날씨 파싱, PIN, 서명 만료 읽기)은 Swift 패키지 `KidBoardCore`에 둡니다. 이 패키지는 Xcode 없이 `swift test`로 테스트합니다. iPad 앱은 XcodeGen으로 만든 SwiftUI 프로젝트입니다. 앱이 SwiftData에 데이터를 저장하고 `KidBoardCore`의 값 타입으로 바꿔 계산합니다. 자동 재설치는 zsh 스크립트와 LaunchAgent입니다.

**Tech Stack:** Swift 6, SwiftUI, SwiftData, swift-testing(`import Testing`), CryptoKit, XcodeGen, Open-Meteo API, zsh, launchd

**Spec:** `docs/superpowers/specs/2026-11-19-kid-board-design.md`

## Global Constraints

- 최소 iPadOS 17.0, iPad 전용(`TARGETED_DEVICE_FAMILY = 2`), 가로 방향만 지원합니다.
- `KidBoardCore`의 플랫폼은 `.iOS(.v17)`, `.macOS(.v14)`입니다. 외부 패키지 의존성을 두지 않습니다.
- 화면 문구는 한국어입니다. 초등 저학년이 읽을 수 있게 짧게 씁니다.
- 날씨 외의 기능은 오프라인으로 동작합니다. 앱은 위치 권한을 요청하지 않습니다.
- 시각 계산은 주입한 `Calendar`로 합니다. 앱은 `Calendar.current`를 넘기고, 테스트는 `Asia/Seoul` 시간대의 그레고리력을 넘깁니다.
- 참조 화면의 일러스트를 복제하지 않습니다. 그래픽은 SwiftUI 도형과 이모지로 새로 만듭니다.
- 팀 ID와 번들 ID는 저장소에 커밋하지 않습니다. `Config/Local.xcconfig`(git 제외)에 둡니다.
- 커밋 메시지는 영어 Conventional Commits 형식으로 씁니다. 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`를 붙입니다.

## Review Focus

1. **요일 시각이 없는 날**: 부모가 어떤 요일의 시각을 정하지 않았으면 등교 시각 없음, 잘 준비 시각 21:30으로 계산합니다. 보드가 멈추거나 빈 화면이 되면 안 됩니다. (Task 3 테스트)
2. **자정 경계**: 23:59:59에서 00:00:00으로 넘어가면 보드가 새 날짜의 할 일과 빈 완료 상태를 보여 줍니다. (Task 3 테스트)
3. **오늘 할 일이 0개인 자녀**: 진행률 계산이 0으로 나누지 않습니다. 별 도장을 주지 않습니다. (Task 2, Task 3 테스트)
4. **마감 시각 정각의 누르기**: 현재 시각이 등교 시각과 같으면 저녁 시간대입니다. 아침 할 일의 완료 변경을 거부합니다. (Task 3 테스트)
5. **첫 실행에 인터넷이 없음**: 캐시가 없고 요청도 실패하면 날씨 상태는 "정보 없음"이고 앱은 계속 동작합니다. (Task 5 테스트)

**Files:**

**Interfaces:**
- Consumes: Task 1의 모든 타입
- Produces:
  - `public struct ScheduledTask: Identifiable, Hashable, Sendable { task: TaskInfo; slot: TimeSlot; var id: UUID { task.id } }`
  - `public struct DaySummary: Hashable, Sendable { done: Int; total: Int; var isStar: Bool { total > 0 && done == total } }`
  - `public struct ScheduleEngine: Sendable`
    - `init(calendar: Calendar)`
    - `func tasks(childID: UUID, on day: DayDate, data: BoardData) -> [ScheduledTask]` — 아침 시간대 먼저, 같은 시간대 안에서는 `order` 오름차순
    - `func summary(childID: UUID, on day: DayDate, data: BoardData) -> DaySummary`
    - `func times(childID: UUID, on day: DayDate, data: BoardData) -> DailyTimesInfo` — 없으면 `schoolTime: nil`, `bedTime: 21:30`
  - `public enum ScheduleEditor`
    - `static func change(_ schedules: [TaskScheduleInfo], taskID: UUID, slot: TimeSlot, weekdays: Set<Weekday>, today: DayDate, calendar: Calendar, newID: UUID = UUID()) -> [TaskScheduleInfo]`

할 일이 어떤 날짜에 나타나는 조건은 세 가지를 모두 만족할 때입니다.
1. 할 일의 `archivedOn`이 `nil`이거나 그 날짜보다 뒤입니다.
2. 그 날짜가 `startOn` 이상이고 `endOn` 이하(`endOn`이 `nil`이면 제한 없음)인 일정이 있습니다.
3. 그 일정의 `weekdays`에 그 날짜의 요일이 들어 있습니다.

`ScheduleEditor.change` 규칙은 다음과 같습니다.
- 현재 유효한 일정의 `startOn`이 `today`이면 그 일정을 그대로 고칩니다.
- 그렇지 않으면 현재 유효한 일정의 `endOn`을 `today - 1일`로 바꿉니다. 그다음 `startOn = today`인 새 일정을 `newID`로 추가합니다.

### Task 3: 보드 상태 계산 (시간대, 카운트다운, 완료 가능 여부)

**Files:**

- Test: `Packages/KidBoardCore/Tests/KidBoardCoreTests/BoardStateEngineTests.swift`

**Interfaces:**
- Consumes: `ScheduleEngine`, `ScheduledTask`, `BoardData`, `DayDate`
- Produces:
  - `public enum BoardPhase: Hashable, Sendable { case morning(deadline: Date), evening(deadline: Date), allDay(deadline: Date), finished(allDone: Bool) }`
  - `public struct ChildBoardState: Hashable, Sendable { child: ChildInfo; day: DayDate; phase: BoardPhase; visibleTasks: [ScheduledTask]; doneTaskIDs: Set<UUID>; nowTaskID: UUID?; remaining: Int; progress: Double }`
  - `public struct BoardStateEngine: Sendable`
    - `init(calendar: Calendar)`
    - `func state(for child: ChildInfo, now: Date, data: BoardData) -> ChildBoardState`
    - `func canToggle(taskID: UUID, childID: UUID, now: Date, data: BoardData) -> Bool`
  - `public enum BoardCopy` — 화면 문구 상수
    - `static func countdownLabel(_ phase: BoardPhase) -> String?` — morning: "등교까지", evening·allDay: "잘 준비까지", finished: `nil`
    - `static func remainingText(_ remaining: Int) -> String` — 1 이상: "할 일 \(n)개 남았어!", 0: "다 했어! 최고야!"
    - `static func finishedText(allDone: Bool) -> String` — true: "오늘 수고했어!", false: "내일 또 해 보자"

시간대 판정 규칙(스펙 7.3)은 다음과 같습니다. `school`, `bed`는 오늘 날짜의 해당 시각입니다.
1. `school`이 있고 `now < school`이면 `.morning(deadline: school)`입니다. 아침 할 일만 보입니다.
2. `school`이 있고 `school <= now < bed`이면 `.evening(deadline: bed)`입니다. 저녁 할 일만 보입니다.
3. `school`이 없고 `now < bed`이면 `.allDay(deadline: bed)`입니다. 모든 할 일이 보입니다.
4. 그 밖에는 `.finished(allDone:)`입니다. `allDone`은 그날 전체 요약의 `isStar`입니다. 보이는 할 일은 `school`이 있으면 저녁 할 일, 없으면 전체입니다.

`nowTaskID`는 보이는 할 일 중 미완료이면서 순서가 가장 앞선 할 일입니다. `.finished`이면 `nil`입니다.
`progress`는 보이는 할 일이 0개이면 0입니다.
`canToggle`은 단계가 `.finished`가 아니고 그 할 일이 `visibleTasks`에 있을 때만 `true`입니다. 완료와 취소에 같은 규칙을 씁니다.

스크립트 순서(스펙 7.8)는 다음과 같습니다.

4. `xcrun devicectl device install app --device "$DEVICE_ID" "$STATE_DIR/DerivedData/Build/Products/Release-iphoneos/KidBoard.app"`을 실행합니다.
5. `xcrun devicectl device process launch --device "$DEVICE_ID" --terminate-existing "$BUNDLE_ID"`를 실행합니다. 구현자는 `xcrun devicectl device process launch --help`로 플래그 이름을 확인합니다.
