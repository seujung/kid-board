# 자녀용 할 일 보드 iPad 앱 설계

작성일: 2026. 11. 19.

## 1. 의도와 배경

사용자는 자녀 2명이 등교 전 할 일과 요일별 할 일을 스스로 확인하고 끝내도록 돕는 보드를 원합니다.
출발점은 Threads 게시글(@moon_sabooo)입니다.
게시글 작성자는 9살 딸에게 할 일 대시보드를 만들어 주었습니다.
작성자에 따르면 아이가 할 일을 빨리 끝내고 잘 시간을 더 확보하게 되었습니다.
이전에 작성자는 칭찬 스티커로 동기를 주었습니다.

이 앱은 집의 iPad 한 대에 상시 켜 두는 보드입니다.
자녀가 iPad 화면에서 직접 완료를 누릅니다.
부모가 같은 iPad에서 자녀와 할 일을 등록합니다.

### 참조 화면

사용자가 참조 화면(`~/Desktop/screenshot/Screenshot 2026-11-19 at 10.49.06.png`)을 주었습니다.
참조 화면의 구성은 다음과 같습니다.

1. 상단 배경은 밤 캠핑장 일러스트입니다. 왼쪽에 날짜와 큰 시계가 있습니다.
2. 오른쪽 카드는 "잘 준비까지 10분 07초" 카운트다운과 진행 막대("할 일 2개 남았어!")를 보여 줍니다.
3. 가운데 줄은 요일 카드입니다. 각 카드에 날짜와 완료 수(예: 5/7)가 표시됩니다. 할 일을 모두 끝낸 날에는 별 도장이 찍힙니다. 오늘 카드에는 "오늘" 표시가 붙습니다.
4. 하단은 "오늘 할 일 5/7" 카드 목록입니다. 끝낸 카드에는 "참 잘했어요" 도장이 찍힙니다. 다음에 할 카드에는 "지금 하자!" 표시가 붙습니다.

이 앱은 참조 화면의 정보 구성과 동작을 따릅니다.
일러스트와 그래픽은 참조 화면을 복제하지 않고 새로 만듭니다.

## 2. 목표, 비목표, 반목표

### 목표

- 자녀 2명의 보드를 한 화면에 동시에 표시합니다.
- 아침 등교 전 할 일과 요일별 반복 할 일을 표시합니다.
- 자녀가 카드를 눌러 할 일을 완료합니다. 완료하면 도장이 찍힙니다.
- 마감 시각까지 남은 시간과 남은 할 일 수를 표시합니다.
- 오늘 날씨를 표시합니다.
- 부모가 자녀 등록과 일정 등록을 iPad에서 직접 합니다.
- iPad가 화면을 끄지 않고 보드를 계속 표시합니다.
- 유료 개발자 계정 없이 설치를 유지합니다. Mac의 자동 재설치 스크립트가 7일 만료 전에 앱을 다시 설치합니다.

### 비목표

- App Store 배포
- 부모 휴대폰 앱, 원격 등록, 기기 간 동기화
- 서버와 회원 가입
- 자녀 3명 이상 동시 표시
- 포인트 상점, 보상 교환 같은 경제 시스템

### 반목표

다음 결과가 생기면 기능이 동작해도 실패로 봅니다.

- 자녀가 보드를 보고도 지금 무엇을 해야 하는지 바로 알 수 없습니다.
- 부모 설정 화면이 자녀 손에 쉽게 열려서 할 일이 바뀝니다.
- 재설치 실패를 부모가 모르고 지나가서 아침에 앱이 실행되지 않습니다.
- 재설치나 앱 업데이트 때문에 등록한 자녀와 할 일이 사라집니다.

## 3. 제약

- 기기: 사용자의 iPad 한 대입니다. 가로 방향으로 거치합니다.
- 설치: 무료 Apple 계정으로 서명합니다. 이 서명은 7일 뒤 만료됩니다. 무료 계정으로는 한 기기에 앱을 3개까지 설치합니다.
- 설치 환경: 사용자의 Mac mini가 자동 재설치를 맡습니다. Mac mini는 24시간 켜져 있습니다. Mac mini와 iPad는 같은 Wi-Fi에 있습니다. Mac mini에 Xcode가 설치되어 있어야 합니다.
- 상시 표시: iPad는 보드를 24시간 켜 둡니다. 사용법 유도 접근(Guided Access)도 계속 켜 둡니다.
- 네트워크: 날씨만 인터넷이 필요합니다. 나머지 기능은 오프라인으로 동작합니다.
- 언어: 화면 문구는 한국어입니다. 자녀 연령대(초등 저학년)에 맞춰 짧게 씁니다.

## 4. 개발 가능 여부

결론: 모든 요구 사항을 개발할 수 있습니다.
위험 요소는 자동 재설치 하나이고, 개발 초기에 실제 기기로 검증합니다.

| 요구 사항 | 판단 | 근거와 위험 |
|---|---|---|
| 자녀 2명 동시 표시 | 가능 | SwiftUI 화면 분할로 구현합니다. |
| 아침 할 일, 요일별 반복 할 일 | 가능 | 할 일마다 요일 집합과 시간대를 저장합니다. |
| 카운트다운, 진행 막대, 도장 | 가능 | SwiftUI 타이머와 애니메이션으로 구현합니다. |
| 날씨 표시 | 가능 | Open-Meteo는 키 없이 쓰는 무료 날씨 API입니다. 비상업적 사용 조건으로 무료입니다. |
| 자녀 등록, 일정 등록 | 가능 | iPad 안에 SwiftData로 저장합니다. |
| 화면 꺼짐 방지 | 가능 | 앱이 `UIApplication.shared.isIdleTimerDisabled`를 켭니다. 자녀가 앱을 나가지 못하게 하려면 iPad의 "사용법 유도 접근(Guided Access)"을 함께 씁니다. |
| 무료 계정 7일 만료 대응 | 가능, 검증 필요 | `xcodebuild`와 `xcrun devicectl`로 빌드, 서명, 무선 설치, 앱 실행을 자동화합니다. 사용법 유도 접근이 켜진 상태에서 설치와 재실행이 되는지는 확인하지 않았습니다. 앱이 종료될 때 사용법 유도 접근이 풀리는지도 확인하지 않았습니다. Xcode의 Apple 계정 로그인이 주기적으로 풀리는지도 확인하지 않았습니다. |

## 5. 접근 방식

검토한 방식은 세 가지입니다.

1. **SwiftUI iPad 앱 + 무료 계정 + 자동 재설치 (선택)**
   - 장점: 오프라인 동작, 화면 꺼짐 방지, 데이터 보존이 확실합니다. 비용이 없습니다.
   - 단점: Mac이 켜져 있어야 자동 재설치가 동작합니다. 재설치 순간에 앱이 잠시 종료됩니다.
2. **SwiftUI iPad 앱 + 유료 개발자 계정**
   - 장점: 1년 동안 재설치가 필요 없습니다.
   - 단점: 연 99달러가 듭니다.
   - 설계는 1번과 같습니다. 나중에 계정을 바꾸면 자동 재설치 스크립트만 끕니다.
3. **홈 화면에 추가하는 웹 앱**
   - 장점: 서명 만료와 비용이 없습니다.
   - 단점: Safari 저장소의 데이터가 브라우저 데이터 삭제와 함께 사라집니다. 화면 꺼짐 방지가 앱보다 불안정합니다.

사용자가 1번을 선택했습니다.
선택 이유는 iPad 앱을 원했고, 같은 Wi-Fi에서 Mac이 재설치를 자동으로 처리하면 비용 없이 유지할 수 있기 때문입니다.
부모 휴대폰에서 원격 등록하는 서버 방식은 요청 범위 밖이고 서버 운영 부담이 있어서 제외했습니다.

## 6. 사용자가 정한 사항

- 플랫폼: SwiftUI iPad 앱
- 설치: 무료 Apple 계정 서명, 24시간 켜진 Mac mini가 같은 Wi-Fi로 자동 재설치
- 화면: 자녀 2명의 보드를 한 화면에 동시에 표시
- 할 일 종류: 아침 등교 전 할 일, 요일별 반복 할 일(같은 할 일이 정해진 요일마다 다시 나타남)
- 기능: 자녀 등록, 일정 등록, 날씨 표시
- 화면 참조: 사용자가 준 참조 화면
- 상시 표시: 보드를 24시간 켜 두고, 22:00~06:00에는 야간 모드로 화면을 어둡게 합니다.
- 만료 경고: iPad 앱이 자기 서명 만료일을 읽고, 만료 2일 전부터 보드에 경고를 표시합니다.
- 늦은 완료: 마감 시각이 지난 시간대의 할 일은 완료로 바꿀 수 없습니다. 아침 할 일을 놓친 날은 별 도장을 받지 못합니다.

## 7. 설계

### 7.1 용어

- **보드**: 자녀가 보는 기본 화면입니다.
- **부모 모드**: 자녀, 할 일, 시각, 날씨 지역을 등록하는 화면입니다. PIN으로 잠급니다.
- **시간대**: 할 일이 속한 구간입니다. "아침"과 "저녁" 두 가지입니다.
- **마감 시각**: 시간대가 끝나는 시각입니다. 아침의 마감 시각은 등교 시각이고, 저녁의 마감 시각은 잘 준비 시각입니다.
- **완료 기록**: 자녀가 특정 날짜에 특정 할 일을 끝냈다는 기록입니다.

### 7.2 보드 화면

iPad를 가로로 두고 화면을 위아래로 나눕니다.
위쪽 공통 영역에는 날짜, 시계, 날씨를 하나만 표시합니다.
아래쪽은 좌우로 나눠 자녀마다 패널 하나를 둡니다.

```
┌─────────────────────────────────────────────────────────────────┐
│  11월 19일 목요일   오전 7:42:10           ☀ 3°  최고 9° 최저 -1° │
│  (시간대에 따라 아침/밤으로 바뀌는 배경 일러스트)    비 올 확률 10%   │
├────────────────────────────────┬────────────────────────────────┤
│ 🐰 첫째                         │ 🐻 둘째                         │
│ 등교까지 18분 20초               │ 등교까지 18분 20초               │
│ ▓▓▓▓▓▓░░░░ 할 일 2개 남았어!     │ ▓▓░░░░░░░░ 할 일 3개 남았어!     │
│ 월  화  수 [목] 금  토  일       │ 월  화  수 [목] 금  토  일       │
│ ★   ★  4/5 3/5 0/4 0/2 0/2     │ ★  3/4  ★  1/4 0/4 0/2 0/2     │
│ 아침 할 일 3/5                   │ 아침 할 일 1/4                  │
│ (참잘)(참잘)(참잘)(지금 하자!)( ) │ (참잘)(지금 하자!)( )( )         │
└────────────────────────────────┴────────────────────────────────┘
```

동작 규칙은 다음과 같습니다.

1. 자녀 패널은 부모가 정한 순서대로 왼쪽, 오른쪽에 놓입니다. 자녀가 1명이면 패널 하나가 전체 너비를 씁니다.
2. 패널마다 자녀 테마 색을 씁니다. 두 자녀의 패널이 한눈에 구별되어야 합니다.
3. 할 일 카드에는 순서 번호, 이모지 아이콘, 제목이 있습니다.
4. 자녀가 미완료 카드를 누르면 완료 기록이 생기고 "참 잘했어요" 도장이 찍힙니다.
5. 자녀가 완료 카드를 누르면 "취소할까요?" 확인이 표시됩니다. 자녀가 확인하면 완료 기록이 지워집니다.
6. 미완료 카드 중 순서가 가장 앞선 카드에 "지금 하자!" 표시가 붙습니다.
7. 진행 막대는 현재 시간대의 완료 비율을 보여 줍니다. 모두 끝내면 축하 문구와 애니메이션이 표시됩니다.
8. 요일 카드에는 그날 전체(아침과 저녁) 할 일의 완료 수가 표시됩니다. 지난 날에 모두 끝냈으면 별 도장이 찍힙니다.
9. 자녀가 다른 요일 카드를 누르면 그날 할 일 목록을 보여 줍니다. 지난 날과 앞으로의 날은 보기만 하고 완료를 바꾸지 못합니다. 30초 동안 입력이 없으면 오늘로 돌아옵니다.

### 7.3 시간대와 카운트다운

1. 부모는 자녀마다 요일별 등교 시각과 잘 준비 시각을 정합니다. 등교하지 않는 요일은 등교 시각을 비워 둡니다.
2. 현재 시각이 등교 시각 이전이면 보드가 아침 시간대를 표시합니다. 카운트다운 문구는 "등교까지"입니다.
3. 등교 시각 이후에는 보드가 저녁 시간대를 표시합니다. 카운트다운 문구는 "잘 준비까지"입니다.
4. 등교 시각이 없는 요일에는 아침 할 일과 저녁 할 일을 한 목록으로 표시합니다. 마감 시각은 잘 준비 시각입니다.
5. 마감 시각이 지나면 카운트다운 대신 "오늘 수고했어!" 또는 "내일 또 해 보자"를 표시합니다. 할 일이 남았는지에 따라 문구를 고릅니다.
6. 마감 시각이 지난 시간대의 할 일은 완료로 바꿀 수 없습니다. 그래서 아침 할 일을 다 끝내지 못하고 등교 시각이 지나면 그날 별 도장을 받지 못합니다. 저녁 할 일은 아침 시간대에 미리 완료할 수 없습니다.
7. 자정이 지나면 보드가 새 날짜의 할 일을 표시합니다. 완료 기록은 날짜별로 저장하므로 별도의 초기화가 필요 없습니다.
8. 공통 헤더의 배경 일러스트는 자녀의 시간대가 아니라 현재 시각으로 정합니다. 06:00~18:00에는 낮 풍경, 그 밖의 시각에는 밤 풍경을 씁니다. (제 결정)

두 자녀의 등교 시각이 다르면 패널마다 다른 카운트다운이 표시됩니다.

### 7.3.1 야간 모드

1. 22:00~06:00에 앱이 화면 밝기를 최저로 낮춥니다. 보드 위에 어두운 막을 덮고 시계만 크게 표시합니다.
2. 누군가 화면을 누르면 30초 동안 보드를 평소 밝기로 표시합니다.
3. 06:00에 앱이 야간 모드 진입 전의 화면 밝기로 되돌립니다.

### 7.4 날씨

1. 부모가 부모 모드에서 지역 이름을 검색해 날씨 지역을 정합니다. 앱은 Open-Meteo 지오코딩 API로 좌표를 찾습니다. 그래서 위치 권한을 요청하지 않습니다.
2. 앱은 Open-Meteo 예보 API에서 현재 기온, 날씨 상태, 오늘 최고·최저 기온, 오늘 강수 확률을 가져옵니다.
3. 앱은 30분마다 날씨를 새로 가져옵니다.
4. 요청이 실패하면 앱은 마지막으로 받은 날씨와 받은 시각을 표시합니다. 날씨 정보가 3시간보다 오래되면 날씨 영역을 흐리게 표시합니다.
5. 오늘 강수 확률이 50% 이상이면 "우산 챙기기!" 안내를 날씨 영역에 표시합니다. 안내는 두 자녀 중 늦은 쪽의 등교 시각까지 표시합니다. (제 결정)

### 7.5 부모 모드

1. 부모가 보드 오른쪽 위의 설정 아이콘을 3초 동안 누릅니다.
2. 앱이 4자리 PIN 입력 화면을 표시합니다. 첫 실행 때 부모가 PIN을 정합니다.
3. PIN이 맞으면 부모 모드가 열립니다. 2분 동안 입력이 없으면 보드로 돌아갑니다.
4. PIN이 5회 연속 틀리면 앱이 1분 동안 입력을 막습니다.
5. 부모가 PIN을 잊으면 PIN 화면의 "PIN을 잊었어요"를 누릅니다. 앱이 두 자리 수 곱셈 문제 3개를 냅니다. 부모가 모두 맞히면 새 PIN을 정합니다. (제 결정)

부모 모드의 기능은 다음과 같습니다.

- **자녀 관리**: 자녀를 추가, 수정, 삭제합니다. 항목은 이름, 이모지 아바타, 테마 색, 표시 순서입니다. 보드에는 최대 2명을 표시합니다.
- **할 일 관리**: 자녀마다 할 일을 추가, 수정, 삭제, 순서 변경합니다. 항목은 제목, 이모지 아이콘, 시간대(아침 또는 저녁), 반복 요일입니다. 한 할 일을 다른 자녀에게 복사하는 기능도 둡니다.
- **시각 설정**: 자녀마다 요일별 등교 시각과 잘 준비 시각을 정합니다.
- **날씨 지역 설정**: 지역을 검색하고 고릅니다.
- **완료 기록 보기**: 자녀별로 최근 4주의 날짜별 완료 수를 봅니다.
- **PIN 변경**

할 일을 삭제해도 지난 완료 기록은 남습니다.
할 일 수정은 항목에 따라 반영 범위가 다릅니다. (제 결정)

- 제목과 아이콘을 바꾸면 지난 날짜를 포함한 모든 날짜에 반영합니다.
- 시간대나 반복 요일을 바꾸면 오늘부터 반영합니다. 지난 날짜의 완료 수는 그날 유효했던 설정으로 계산합니다.

### 7.6 데이터 모델

SwiftData로 iPad 안에 저장합니다.

- `Child`: id, 이름, 아바타 이모지, 테마 색, 표시 순서
- `TaskItem`: id, 자녀 id, 제목, 아이콘 이모지, 순서, 생성일, 보관일(없을 수 있음)
- `TaskSchedule`: 할 일 id, 시간대, 반복 요일 집합, 적용 시작일, 적용 종료일(없을 수 있음)
- `DailyTimes`: 자녀 id, 요일, 등교 시각(없을 수 있음), 잘 준비 시각
- `Completion`: 자녀 id, 할 일 id, 날짜, 완료 시각
- `AppSettings`: PIN 해시, 날씨 지역 이름, 위도, 경도
- `WeatherCache`: 마지막으로 받은 날씨, 받은 시각

삭제한 할 일은 지우지 않고 보관일을 기록합니다. 그래서 지난 완료 기록이 할 일을 계속 가리킵니다.
부모가 시간대나 반복 요일을 바꾸면 앱이 기존 `TaskSchedule`에 어제를 적용 종료일로 기록합니다. 그다음 오늘을 적용 시작일로 하는 새 `TaskSchedule`을 만듭니다.

### 7.8 자동 재설치 (M7)

1. launchd가 매일 03:00에 스크립트를 실행합니다.
2. 스크립트가 마지막 설치 날짜를 읽습니다. 설치 후 5일이 지나지 않았으면 종료합니다.
3. 스크립트가 `xcodebuild -allowProvisioningUpdates`로 앱을 빌드합니다. 이때 Xcode가 서명을 새로 받습니다.
4. 스크립트가 `xcrun devicectl device install app`으로 Wi-Fi를 통해 iPad에 설치합니다.
5. 스크립트가 `xcrun devicectl device process launch`로 보드 앱을 다시 실행합니다.
6. 성공하면 스크립트가 마지막 설치 날짜를 기록합니다.
7. 실패하면 스크립트가 Mac mini 알림을 띄우고 로그를 남깁니다. 다음 날 03:00에 다시 시도합니다. 만료까지 2일의 여유가 있습니다.

실행 조건은 다음과 같습니다.

- 스크립트는 사용자 세션의 LaunchAgent로 실행합니다. 서명에 로그인 키체인이 필요하기 때문입니다.
- Mac mini가 재부팅 후에도 사용자 세션으로 돌아와야 합니다. 설치 안내 문서에 자동 로그인 설정을 적습니다. FileVault가 켜져 있으면 자동 로그인이 되지 않으므로 이 제약도 적습니다.
- Mac mini는 24시간 켜져 있으므로 `pmset` 깨우기는 쓰지 않습니다. 설치 안내 문서에 "잠자기 방지" 설정을 적습니다.

설치 안내 문서에는 iPad 첫 페어링, "네트워크로 연결" 설정, 개발자 모드 켜기, 개발자 인증서 신뢰 설정도 적습니다.

### 7.9 서명 만료 경고

부모가 Mac mini 알림을 놓칠 수 있습니다. 그래서 iPad 앱도 만료를 알립니다.

1. 앱이 실행될 때 앱 번들 안의 `embedded.mobileprovision`에서 만료일을 읽습니다.
2. 만료까지 2일 이하가 남으면 보드 오른쪽 위에 "앱 다시 설치 필요 (N일 남음)" 경고를 표시합니다.
3. 경고는 자녀 화면을 가리지 않는 작은 크기로 표시합니다.

### 7.10 첫 시험 설치

개발 첫 단계에서 자동 재설치 흐름을 실제 Mac mini와 iPad로 시험합니다.
시험 항목은 다음과 같습니다.

1. 사용법 유도 접근이 켜진 상태에서 무선 설치가 되는지 확인합니다.
2. 재설치로 앱이 종료될 때 사용법 유도 접근이 풀리는지 확인합니다.
3. 스크립트가 앱을 다시 실행한 뒤 사용법 유도 접근이 다시 적용되는지 확인합니다.
4. 재설치 후 등록한 데이터가 남아 있는지 확인합니다.

2번에서 사용법 유도 접근이 풀리고 3번에서 다시 적용되지 않으면, 부모가 재설치 다음 날 아침에 사용법 유도 접근을 다시 켜야 합니다. 이 경우 앱이 재설치 직후 첫 실행에서 "사용법 유도 접근을 다시 켜 주세요" 안내를 표시합니다.

### 7.11 테스트

- M2 일정 계산은 단위 테스트로 확인합니다. 요일, 등교 시각 유무, 자정 경계, 시간대 경계, 늦은 완료 차단, 할 일 수정 시점을 다룹니다.
- M5 날씨는 응답 파싱과 캐시 동작을 단위 테스트로 확인합니다.
- M3, M4 화면은 SwiftUI 미리보기와 실제 iPad로 확인합니다.
- M7은 실제 Mac mini와 iPad로 확인합니다(7.10).

## 8. 빌더에게 맡기는 부분

- Xcode 프로젝트 구성 방식. 제 제안은 XcodeGen(`project.yml`로 Xcode 프로젝트를 만드는 도구)입니다. 프로젝트 정의가 텍스트로 남아 자동 재설치 스크립트와 잘 맞습니다.
- 최소 iPadOS 버전. SwiftData를 쓰려면 iPadOS 17 이상이 필요합니다. 사용자의 iPad가 iPadOS 17을 지원하는지 확인합니다.
- 배경 일러스트, 도장, 축하 애니메이션의 세부 그래픽
- 테마 색 목록, 이모지 선택 화면의 구성
- 첫 실행 예시 데이터의 내용
- 날씨 상태 코드와 아이콘의 대응
- iPad 화면 크기별 배치 조정

## 9. 제가 정한 사항 (사용자 확인 필요)

아래 사항은 사용자가 정하지 않았습니다. 제가 정했습니다.

- "일정 등록"을 할 일 등록과 요일별 시각 설정으로 해석했습니다. 현장학습 같은 단발성 일정은 넣지 않았습니다.
- 시간대를 아침과 저녁 두 가지로 나눴습니다. 저녁 마감 시각은 참조 화면처럼 잘 준비 시각입니다.
- 요일 카드를 월~일 7칸으로 했습니다. 참조 화면은 월~토 6칸입니다.
- 부모 모드를 설정 아이콘 3초 누르기와 4자리 PIN으로 잠급니다.
- 자녀가 완료를 취소할 때 확인 창을 거칩니다.
- 날씨 지역을 위치 권한 대신 지역 검색으로 정합니다.
- 보상은 도장과 별만 둡니다. 누적 스티커나 보상 교환은 넣지 않았습니다.
- 공통 배경은 현재 시각으로 낮과 밤을 정합니다(06:00~18:00 낮).
- 우산 안내는 두 자녀 중 늦은 쪽의 등교 시각까지 표시합니다.
- PIN 분실 시 곱셈 문제 3개로 부모를 확인하고 PIN을 다시 정합니다.
- 제목과 아이콘 수정은 모든 날짜에, 시간대와 요일 수정은 오늘부터 반영합니다.
- 야간 모드에서 화면을 누르면 30초 동안 평소 밝기로 표시합니다.
